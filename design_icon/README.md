# 应用图标

`icon.svg` 是唯一的源文件。所有平台的图标产物都由它生成，改图标只改这一个文件，
然后跑脚本重新生成，不要手工去 P 位图。

```
python design_icon/build_icons.py     # 生成全部产物
python design_icon/verify_icons.py    # 核对格式/尺寸，并量 16px 的墨色占比
```

产物（共 6 个，均由脚本覆盖写入）：

| 路径 | 规格 |
| --- | --- |
| `web/public/icon.svg` | 源文件副本 |
| `web/public/favicon.ico` | 16/24/32/48/64/128/256 |
| `web/public/apple-touch-icon.png` | 180 |
| `desktop/src-tauri/icons/icon.png` | 512 |
| `desktop/src-tauri/icons/icon.ico` | 同 favicon |
| `desktop/src-tauri/icons/icon.icns` | 1024 |

## 设计约束

图案是「中心枢纽 + 六向卫星节点」的星丛，表达智能体网络。

**必须撑满画布。** 初版图形只占画布约 54%，节点也偏小，结果在 16px 的
favicon 和任务栏尺寸下碎成一片 1px 灰点，完全不可读。现在卫星外推到贴近边缘、
节点半径 2.3、连线宽 2.1，16px 下墨白像素占整块的 20%（初版约 9%）。

`verify_icons.py` 最后会打印这个占比，改完图标看一眼——**明显低于 15% 就说明
小尺寸又要糊了**。

## 试过但否掉的方向

小尺寸看不清时，第一反应是减少元素，但减到四向或三向会撞上通用符号：

- 四向正交（上下左右）+ 中心点 → 像方向键 / 十字准星
- 三卫星 120° → 像人形 / 奔跑图标
- 同心弧 + 散点 → 像 WiFi
- 中心环 + 环绕圆点 → 像齿轮 / 设置

所以保留六向，靠**加粗填满**而不是减少元素来换取小尺寸可读性。

判断任何改动都要渲染成位图实际看，尤其是 16px——只看数值或大图会误判。
